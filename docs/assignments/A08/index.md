# A8 – Gears

## Objective
- Design a gearbox that can be assembled and disassembled.
- Analyze and size input and output shafts for strength.
- Design journal bearings to support shafts.
- Create a gearbox housing with proper clearance and fastening.
- Use parametric CAD modeling to generate a final design.
- Document calculations, sketches, and lessons learned.

## Assignment Details
For this assignment, I was tasked with designing a gearbox with a 24:9 gear ratio. There were a few assumptions to consider when designing this gearbox that I had to follow through with in my calculations, so I started by listing out my known values and began solving for those, beginning with the shaft.

## Shaft Design
I was given a few values to start with, and by using these along with the equations found in the Machinery's Handbook, I found the max torque of both shafts to be well under 4000 psi. This means that they'll both work well in the design

## Journal bearing designs
The next thing I was tasked with designing was the journal bearings that would be attached to the gear shafts. By using the values we had just found while designing the shaft, we can begin to dissect the length at which we want bearings to be as well as finding what material would work best for our design. With my calculations, I found porous bronze to be a good fit for my design. Using McMaster-Carr, I found well-fitting bearings for both the input and output shafts. These can be found [here](https://www.mcmaster.com/6391K126/)
